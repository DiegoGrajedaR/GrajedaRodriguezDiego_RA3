# ⚔️ Medieval VVVVVV 🛡️

Un joc de plataformes en 2D d'estil retro inspirat en el clàssic *VVVVVV*, ambientat en un castell. Controla a un cavaller per superar els diferents nivells amb les seves trampes.

---

## 📖 Descripció del joc

### 🎮 Gènere
- **Plataformes 2D:** Inspirat directament en la mecànica principal de *VVVVVV*. El jugador ha d'alterar la seva pròpia gravetat per caminar tant pel terra com pel sostre, esquivant obstacles i superant les diferents sales

### 🎨 Visualització i Estètica
- **Estil Visual:** Gràfics *Pixel Art* (estil retro en bits) amb una paleta de colors foscos.
- **Ambientació:** El joc transcorre de nit a l'interior i els voltants d'un castell medieval. El protagonista és un cavaller equipat amb armadura.
- **Perspectiva i Format:** Vista lateral en 2D que segueix al personatge.

---

## 🕹️ Controls (Tecles d'Input)

| Acció | Tecles |
| :--- | :--- |
| **Moure's a l'esquerra** | `A` o `Fletxa Esquerra` (`←`) |
| **Moure's a la dreta** | `D` o `Fletxa Dreta` (`→`) |
| **Canviar / Invertir gravetat** | `Espai` |
